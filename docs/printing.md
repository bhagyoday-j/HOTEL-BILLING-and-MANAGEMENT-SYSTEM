# Printing

Printing is implemented in Phase 8.

Planned capabilities:

- A4 / 80mm / 58mm templates
- Invoice, receipt, KOT, daily report
- Silent print + preview
- Per-purpose printer settings (`INVOICE`, `RECEIPT`, `KOT`)

IPC surface (already stubbed):

- `window.api.print.getPrinters()`
- `window.api.print.testPrint()`
